# Wordnet-Hearing-Test
A project that employs ASR, TTS, and WordNet to inquire basic questions from individuals and evaluate their hearing ability.




Fatehifar M, Munro KJ, Stone MA, Wong D, Cootes T, Schlittenlacher J. Digits-In-Noise Hearing Test Using Text-to-Speech and Automatic Speech Recognition: Proof-of-Concept Study. Trends in Hearing. 2025;29. doi:10.1177/23312165251367625
